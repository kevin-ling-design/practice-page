# Practice Page

A tiny project for practicing the designer-to-code workflow: make a branch, change something, push it, and open a pull request.

## What is in here

- `index.html`: the page content (the words and the button)
- `styles.css`: how it looks (colors, spacing, rounded corners)

To preview it, open `index.html` in your browser.

## Practice tasks

Do these one at a time, each on its own branch:

1. Change the button color to a color you like.
2. Make the button's corners fully rounded (a pill shape).
3. Increase the space inside the card so it feels roomier.
4. Change the heading text to your own name.
5. Add a second, outlined button next to the first one.
